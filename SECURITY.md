# Security policy

## Supported versions

Security fixes are applied to the latest released version and, when
appropriate, to the current `main` branch. Older releases may not receive a
backport.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Send a report
to `me@cbchoi.info` with:

- the affected version or commit;
- steps to reproduce the issue;
- the expected impact; and
- any suggested mitigation.

Avoid including credentials, proprietary RTI files, license data, or unrelated
personal information. The maintainer aims to acknowledge a report within five
business days, then assess its scope and coordinate disclosure after a fix or
mitigation is available.

For ordinary bugs and usage questions, use
[GitHub Issues](https://github.com/eventsim/pyjevsim/issues).
